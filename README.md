# Алгоритмы компьютерной графики

Репозиторий с лабораторными работами по дисциплине «Алгоритмы компьютерной графики».

## О дисциплине

Рассматриваются базовые понятия растровой и векторной графики. Структура растровых изображений. Графические форматы. Доступ к точкам растра в различных средах прикладного программного обеспечения.

Рассматриваются вопросы обработки изображений — изменение яркости, контраста. Построение гистограмм. Обсуждаются вопросы оценки визуального качества изображений, различные метрики. Подробно рассматривается индекс структурного сходства изображений — SSIM (Structure Similarity Index Metric).

Рассматриваются вопросы построения тепловых карт. Подходы к сжатию изображений: сжатие без потерь, сжатие с частичной потерей информации, вейвлет-преобразования.

Даются основы векторной графики, понятие о гладких кривых, кривая Безье — параметрическое уравнение третьего порядка.
